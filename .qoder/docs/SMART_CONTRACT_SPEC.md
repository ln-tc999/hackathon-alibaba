## 1. Payment Manager Contract

### Purpose
Handle pay-as-you-go payments for workflow execution using USDC/ETH.

### Features
- Accept USDC and ETH payments
- Credit system for workflow execution
- Price oracle integration
- Refund mechanism
- Admin controls

### Contract Interface

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

interface IPaymentManager {
    // Events
    event CreditsPurchased(address indexed user, uint256 amount, uint256 credits);
    event CreditsUsed(address indexed user, uint256 credits, string workflowId);
    event PriceUpdated(uint256 newPricePerCredit);
    
    // Functions
    function purchaseCreditsWithETH() external payable returns (uint256 credits);
    function purchaseCreditsWithUSDC(uint256 amount) external returns (uint256 credits);
    function useCredits(uint256 amount, string calldata workflowId) external;
    function getCredits(address user) external view returns (uint256);
    function getPricePerCredit() external view returns (uint256);
}
```

### Key Variables
- `mapping(address => uint256) public credits` - User credit balances
- `uint256 public pricePerCredit` - Price in wei per credit
- `address public usdcToken` - USDC token address
- `address public treasury` - Treasury wallet for collected funds

### Pricing Model
- Initial: 1 credit = 0.001 ETH or equivalent USDC
- Dynamic pricing based on gas costs
- Bulk purchase discounts

## 2. VlowGen NFT Contract

### Purpose
Mint NFTs from workflow outputs with IPFS metadata.

### Features
- ERC-721 standard compliance
- IPFS metadata storage
- Royalty support (ERC-2981)
- Batch minting capability
- Workflow provenance tracking

### Contract Interface

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

interface IVlowGenNFT {
    // Events
    event NFTMinted(
        address indexed owner,
        uint256 indexed tokenId,
        string ipfsHash,
        string workflowId
    );
    
    // Functions
    function mint(
        address to,
        string calldata ipfsHash,
        string calldata workflowId
    ) external returns (uint256 tokenId);
    
    function batchMint(
        address to,
        string[] calldata ipfsHashes,
        string calldata workflowId
    ) external returns (uint256[] memory tokenIds);
    
    function getWorkflowId(uint256 tokenId) external view returns (string memory);
    function getIPFSHash(uint256 tokenId) external view returns (string memory);
}
```

### Metadata Structure

```json
{
  "name": "VlowGen Output #123",
  "description": "Generated by VlowGen workflow",
  "image": "ipfs://QmXxx...",
  "attributes": [
    {
      "trait_type": "Workflow ID",
      "value": "workflow-123"
    },
    {
      "trait_type": "Generation Date",
      "value": "2024-01-15"
    },
    {
      "trait_type": "Model",
      "value": "WAN2.1"
    }
  ],
  "external_url": "https://vlowgen.com/nft/123"
}
```

### Key Variables
- `uint256 private _tokenIdCounter` - Auto-incrementing token ID
- `mapping(uint256 => string) private _ipfsHashes` - Token to IPFS mapping
- `mapping(uint256 => string) private _workflowIds` - Token to workflow mapping
- `uint96 public royaltyBps` - Royalty basis points (e.g., 500 = 5%)

## 3. Mint Node Integration

### Backend Flow

```typescript
// packages/backend/src/nodes/mint-handler.ts

interface MintNodeData {
  type: 'mint';
  ipfsUpload: boolean;      // Auto-upload to IPFS
  mintOnChain: boolean;     // Auto-mint NFT
  recipientAddress?: string; // Optional recipient
}

async function executeMintNode(
  nodeId: string,
  data: MintNodeData,
  inputs: Record<string, any>
): Promise<NodeExecutionResult> {
  // 1. Get image from previous node (WAN2/OpenRouter)
  const imageUrl = inputs.imageUrl;
  
  // 2. Upload to IPFS
  const ipfsHash = await uploadToIPFS(imageUrl);
  
  // 3. Create metadata
  const metadata = createMetadata(ipfsHash, nodeId);
  const metadataHash = await uploadMetadataToIPFS(metadata);
  
  // 4. Mint NFT on-chain
  if (data.mintOnChain) {
    const txHash = await mintNFT(
      data.recipientAddress || userAddress,
      metadataHash,
      workflowId
    );
    
    return {
      status: 'success',
      output: {
        ipfsHash,
        metadataHash,
        txHash,
        nftUrl: `https://opensea.io/assets/...`
      }
    };
  }
  
  return {
    status: 'success',
    output: { ipfsHash, metadataHash }
  };
}
```

## 4. Development Setup

### Prerequisites
- Node.js 18+
- Hardhat or Foundry
- Alchemy/Infura API key
- Wallet with testnet ETH

### Installation

```bash
# Create contracts package
mkdir -p packages/contracts
cd packages/contracts

# Initialize Hardhat
npm init -y
npm install --save-dev hardhat @nomicfoundation/hardhat-toolbox
npx hardhat init

# Install dependencies
npm install @openzeppelin/contracts
npm install @chainlink/contracts  # For price feeds
```

### Configuration


## 8. Gas Optimization

### Strategies
- Use `uint256` instead of smaller types
- Pack struct variables efficiently
- Use `calldata` instead of `memory` for read-only arrays
- Batch operations when possible
- Cache storage variables in memory
- Use events instead of storage for historical data

### Estimated Gas Costs
- Purchase credits: ~50,000 gas
- Mint single NFT: ~80,000 gas
- Batch mint (10 NFTs): ~400,000 gas
