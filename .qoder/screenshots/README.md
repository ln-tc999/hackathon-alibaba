# UI Screenshots

This folder contains screenshots of the VlowGen Platform UI for documentation purposes.

## Screenshot Guidelines

### Naming Convention
- Use descriptive names with dates: `YYYY-MM-DD-feature-name.png`
- Examples:
  - `2024-01-15-ai-chat-interface.png`
  - `2024-01-15-manual-node-palette.png`
  - `2024-01-15-workflow-canvas.png`
  - `2024-01-15-execution-panel.png`

### Recommended Screenshots

#### Main Features
- [ ] **AI Chat Mode** - Full view of chat interface with sample conversation
- [ ] **Manual Mode** - Node palette with all available nodes
- [ ] **Workflow Canvas** - Example workflow with connected nodes
- [ ] **Execution Panel** - Active workflow execution with progress
- [ ] **Navigation Bar** - Minimalist header with logo and wallet connection

#### Detailed Views
- [ ] **Chat Message Flow** - User and AI messages
- [ ] **Node Types** - Individual node cards with icons
- [ ] **Node Connection** - Nodes connected with edges
- [ ] **Error State** - Node with error highlighting
- [ ] **Success State** - Completed workflow execution

#### Responsive Views
- [ ] **Desktop View** - Full layout (1920x1080)
- [ ] **Tablet View** - Medium screen layout (768px)
- [ ] **Mobile View** - Mobile responsive layout (375px)

### Screenshot Specifications
- **Format**: PNG (preferred) or JPG
- **Resolution**: Minimum 1920x1080 for desktop views
- **Quality**: High quality, no compression artifacts
- **Content**: Include realistic sample data
- **Privacy**: Remove any sensitive information (API keys, personal data)

### Tools Recommended
- macOS: Cmd + Shift + 4 (area selection)
- Windows: Windows + Shift + S
- Browser DevTools: Built-in screenshot feature
- Third-party: CleanShot X, Snagit, Lightshot
